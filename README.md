# RB SPA — sitio web, versión 1

Sitio estático de climatización y electricidad, preparado para subir a GitHub. No requiere instalación, dependencias ni proceso de compilación.

## Abrir y publicar

- Para revisar en este equipo, abre `index.html` en un navegador.
- Para GitHub, sube **el contenido de esta carpeta** a la raíz de un repositorio. `index.html` debe quedar en la raíz.
- Después, conecta ese repositorio a Vercel. Selecciona el preset **Other**, deja vacío el comando de compilación y usa `.` como directorio de salida; `index.html` debe seguir en la raíz. Esta web no necesita `vercel.json` ni dependencias.
- Cuando exista un dominio definitivo, añade su URL canónica y la imagen Open Graph absoluta en `index.html`.

## Archivos

- `index.html`: contenido y metadatos.
- `styles.css`: diseño adaptable a escritorio, tablet y celular.
- `script.js`: menú móvil y año del pie de página.
- `assets/`: emblema, favicon e imágenes optimizadas.
- `brief-marca.md`: fuentes, decisiones visuales y datos por confirmar.

## Imágenes y fuentes

El emblema se extrajo y limpió de la fotografía del logo entregada. Las tres fotografías de servicios se generaron con IA como imágenes referenciales; no muestran al equipo ni trabajos reales de RB SPA. No se recibieron fotografías originales de proyectos. El detalle de las fuentes y sus limitaciones está en `brief-marca.md`.
